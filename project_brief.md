# My agent: ordermate
One-liner: A conversational agent that helps shoppers track orders, process returns, and resolve issues with a catalog of retail products and orders.

Tool coverage:
- Memory: customer preferences, shipping address history, return reasons
- Tools: order tracking lookup, return eligibility check, return authorization creation
- Catalog/UI: customer order collection and product items to render as cards/tables
- Image gen: return packaging guides, product replacement visuals
- Sandbox: refund calculations and prorated credit computation

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for calculations, Cloud Trace
